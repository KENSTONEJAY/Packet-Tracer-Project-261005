# Packet-Tracer-Project-261005
#Configure A Wireless Router and Clients

##OVERVIEW 
A Cisco Packet tracer exercise whereby I connected and configured a wireless router and client devices in a home network in order to achieve internet connectivity across the entire network

##What I learned 
- I practiced using copper straight-through and coaxial cable connections with a Home wireless router testing and verifying end-to-end connectivity 
- I configured the Office PC to use an automatically assigned IP address from the DHCP
- Used the default gateway of the PC (which was also the IP address of the Home wireless router) to access the internet
- Accessed the GUI of the Wireless router and reduced the Maximum Number of Users from the default 50 down to 10 (for better security), changed the default admin password, and saved the changes
